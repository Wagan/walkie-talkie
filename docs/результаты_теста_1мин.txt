3. Набор команд
> help
commands:
  help          - list commands
  send        - send [n] test packets
  sendbyte    - send one raw byte
  stat        - link byte/error statistics
  reset       - reset all counters
  dump        - hex of last raw received bytes
  regs        - USART2 registers
  baud        - show/set UART baud
  voice       - voice path stats + rx line errors
  proto       - framing protocol statistics (rx)
  ptt         - ptt on|off (latches tx; blocks rx)
  tone        - tone on [freq]|off (default 1 kHz)
  codec       - codec raw|ulaw|adpcm|codec2
  c2mode      - codec2 mode 3200|2400|1600|1300|700C
  rate        - rate 8000|16000
  decim       - decim fir|avg (16->8 anti-alias)
  headroom    - mic atten before codec (0|3|6|9|12 dB)
  load        - codec core load (us/block, %)
  budget      - channel budget table (HC-12)
  c2load      - Codec2 encode/decode load (bench, no path)
  phy         - phy ttl|rs485 (line physical layer)
  rs485       - rs485 dir stats [guard/wd setters]
