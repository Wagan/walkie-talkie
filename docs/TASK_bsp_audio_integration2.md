КОНТЕКСТ

Проект walkie-talkie (корень репозитория, он же корень проекта CubeIDE) сгенерирован
из Board Selector для STM32F411E-DISCO.

Состояние .ioc на момент этого задания, подтверждено владельцем:
- отключены USB_HOST, USB_OTG_FS, SPI1 — пины освобождены;
- отключены I2S2, I2S3, I2C1 — код перегенерирован, вызовов MX_I2S2_Init,
  MX_I2S3_Init и MX_I2C1_Init в main.c больше нет;
- DMA в конфигураторе не задавался изначально и сейчас не задан.

Принято решение: аудиотракт обслуживается штатным BSP платы из пакета, а не
собственным кодом поверх HAL. Инициализацию I2S2, I2S3, I2C1, обоих потоков DMA и
пересчёт PLLI2S выполняет сам BSP в своих MspInit — поэтому перечисленная периферия в
CubeMX и выключена.

Опора по фактам — docs/REPORT_st_audio_example.md (разбор эталонного примера ST,
коммит ad30dc1). Все нужные пути, имена файлов и параметры взяты оттуда.

Источник файлов: C:\Users\user\STM32Cube\Repository\STM32Cube_FW_F4_V1.28.0
Эталонный пример: Projects\STM32F411E-Discovery\Applications\Audio\Audio_playback_and_record

ЗАДАЧА C. ОБРАБОТЧИКИ ПРЕРЫВАНИЙ

Периферия аудиотракта в CubeMX выключена, поэтому генератор не создал обработчиков ни
для I2S, ни для потоков DMA, которые использует BSP. Без них аудиотракт не заработает.

1. Прочитать stm32f4xx_it.c и stm32f4xx_it.h эталонного примера.
2. Перенести в наши Core/Src/stm32f4xx_it.c и Core/Inc/stm32f4xx_it.h обработчики
   потоков DMA, задействованных аудиотрактом (по отчёту это DMA1_Stream3 на приём с
   микрофона и DMA1_Stream7 на передачу в кодек), вместе с необходимыми объявлениями
   внешних дескрипторов. Если в примере есть также обработчики I2S — перенести и их,
   указав это отдельно.
3. Весь перенесённый код разместить строго внутри блоков USER CODE BEGIN / USER CODE
   END. Это обязательное требование: иначе следующая генерация из CubeMX сотрёт его.
   Если подходящего блока USER CODE в нужном месте нет — доложить, где именно, и не
   вставлять код за пределами блоков.
4. Привести в отчёте фактический текст того, что вставлено, и в какие блоки.
