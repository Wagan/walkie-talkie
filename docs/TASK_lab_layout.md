КОНТЕКСТ

Проект walkie-talkie работает: демо loopback (микрофон через PDM2PCM на кодек,
Fs = 16 кГц) проверено на обоих китах, диагностика по SWO работает, печать звуку не
мешает.

Курс состоит из лабораторных работ. Принято решение: не отдельный проект CubeIDE на
каждую работу, а ОДИН проект, в котором работа выбирается конфигурацией сборки. У
каждой конфигурации свой каталог сборки, поэтому прошивки лабораторных не затирают
друг друга и всегда видно, что залито в кит.

Состав курса (нумерация сквозная, без шага):
- LAB00 — проверка стенда: микрофон на колонки, диагностика по SWO. ГОТОВА, это
  текущий код демо.
- LAB01 — создание проекта с нуля в CubeMX. Единственная работа вне общего проекта,
  кода в этом репозитории для неё не будет.
- LAB02 — провод между китами, байтовый обмен по UART.
- LAB03 — протокол: кадрирование, синхронизация, обработка потерь.
- LAB04 — речь по проводу: сырой PCM, полудуплекс с PTT, буфер джиттера.
- LAB05 — USB Device CDC, консольное меню.
- LAB06 — расчёт границы канала (без железа).
- LAB07 — сжатие речи, вокодер.
- LAB08 — первый радиоканал вместо провода.
- LAB09 — второй радиоканал, включая UWB на DWM3000.
- LAB10 — сравнение каналов по единой методике.

Задача этого шага — только раскладка под LAB00. Код остальных работ не пишем.
