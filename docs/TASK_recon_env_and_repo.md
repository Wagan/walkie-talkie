КОНТЕКСТ

Новый проект walkie-talkie: учебный практический курс для студентов технических вузов.
Смысл курса — научить пользоваться инструментальными средствами и на их основе собрать
пару речевых радиостанций. Этапы: (1) два кита соединены проводом, выбор протокола
передачи; (2) речь через аудио-подсистему китов туда-обратно; (3) вместо провода —
разные по возможностям радиомодули, от узкополосных УКВ до UWB, чтобы был виден
выигрыш и проигрыш каждого канала.

Железо на столе сейчас: рабочий ноутбук, USB-хаб с внешним питанием, два кита
STM32F411E-DISCO со встроенными ST-LINK, два кабеля USB. Есть также пара модулей
UWB DWM3000, но в этом задании они не участвуют.

Разработка прошивок — в STM32CubeIDE.

Рабочая папка: C:\Users\user\STM32CubeIDE\workspace_1.16.0\walkie-talkie
Удалённый репозиторий: git@github.com:Wagan/walkie-talkie.git — публичный, создан
пустым, без README, .gitignore и лицензии. SSH-ключи на этом ноутбуке есть.

Машина: рабочий ноутбук, Windows, оболочка PowerShell 5.1. Оператор && не
поддерживается, разделитель команд — точка с запятой или перевод строки. Дописывать в
файл через Add-Content, а не через >> (последний пишет UTF-16 и портит файл).

Владелец проекта: Ваган Сарукьянов. Прошивку собирает и железо запускает он. Ты
работаешь только с файлами и git.
