# Отчёт: разделение LAB07/LAB08, этап 2 — раздельные адаптеры и расхождение конфигураций

Этап 2 плана `REPORT_lab08_split_recon.md`. Голосовой движок остаётся в `App/Common/voice.{h,c}`;
появились **два тонких адаптера** с разными умолчаниями и наборами команд. **Здесь конфигурации
впервые расходятся намеренно** — ниже явно перечислено, что должно измениться в наблюдаемом поведении
каждой, чтобы отличить задуманное от регресса. Сборка всех семи конфигураций — **0 ошибок, 0
предупреждений**. Прошивка и проверки на железе — за владельцем.

## Что изменено в коде

- **`App/Common/voice.{h,c}`:** `Voice_Init` теперь принимает `(const VoiceConfig *cfg, cmds, ncmds)`
  — стартовые умолчания (кодек/частота/режим/скорость) и набор команд задаёт работа. Добавлены две
  curated-таблицы команд и геттеры `Voice_CmdsLab07`/`Voice_CmdsLab08`. Движок (тракт, обработчики
  команд) не менялся — только точка входа параметризована.
- **`App/Labs/speech.c`** (LAB07, guard `#if LAB_ID==7`): конфиг провода `{raw, 16 кГц, 3200, 921600}`
  + набор `Voice_CmdsLab07`.
- **`App/Labs/radio_voice.c`** (LAB08, guard `#if LAB_ID==8`, НОВЫЙ): конфиг эфира `{Codec2, 8 кГц,
  3200, 9600}` + набор `Voice_CmdsLab08`. Физслой ttl (умолчание — у HC-12 нет вывода направления).
- `speech.c` guard вернулся к `==7` (обслуживал обе на этапах 0–1).

## Наблюдаемое поведение — LAB07 «сжатие на проводе»

**Умолчания при старте (ИЗМЕНИЛИСЬ относительно этапа 1):**
- кодек **raw** (было codec2), частота **16000 Гц** (было 8000), линия **921600** (было 9600).
- Шапка старта: `LAB07 ready: codec=raw rate=16000 Hz baud=921600. Hold PA0 to talk. 'help'.`
  (текст шапки тоже изменился — теперь общий, печатает фактические значения).
- `voice` при старте: `codec=raw rate=16000 Hz … baud=921600`. **Строки `codec2:` НЕТ** (она печатается
  только когда выбран codec2) — это норма для дефолта raw.

**Набор команд (`help`):** `send, sendbyte, stat, reset, dump, regs, baud, voice, proto, ptt, tone,
codec, rate, decim, headroom, load, budget, c2load, phy, rs485` (+ встроенный `help`). Лесенка кодеков
и отладочные инструменты; RS-485 стенд (`phy/rs485`) остаётся здесь как отладочный.

**Числа `voice` на LAB07 по умолчанию НЕ совпадут с эталоном** (эталон снят на Codec2/8к, а тут
raw/16к) — это НЕ регресс. Чтобы сверить тракт с codec2-поведением, на LAB07 сначала `codec codec2`
(тогда c2mode фиксирован 3200 — команды `c2mode` в LAB07 нет; prefill фиксирован 60 — команды
`prefill` нет).

## Наблюдаемое поведение — LAB08 «речь по радио»

**Умолчания при старте (функционально те же, что тестировались на 50 м):**
- кодек **Codec2**, режим **3200**, частота **8000 Гц**, линия **9600**, физслой **ttl**.
- Шапка: `LAB08 ready: codec=codec2 rate=8000 Hz baud=9600. Hold PA0 to talk. 'help'.`
- **LAB08 должен воспроизвести ЭТАЛОН** по полям: `enc avg ~12613`, `dec avg ~8940`,
  `probeA over=0`, `qover=0`, `ring_over=0`, `loop_max ~32000/49759`, `under 1–2`, `fe=0`, потери
  только `txdrop` (линия ~88 %). Это маркеры отсутствия регресса — тракт не менялся.

**Набор команд (`help`) — УЗКИЙ (изменился):** `reset, codec, c2mode, prefill, budget, voice, ptt,
stat` (+ встроенный `help`). **Убраны** относительно этапа 1: `send, sendbyte, dump, regs, baud,
proto, tone, rate, decim, headroom, load, c2load, phy, rs485` — ввод их на LAB08 даст «unknown
command». Это намеренно (полевая рация, узкий набор), НЕ регресс.

## Маркеры РЕГРЕССА (если увидите — это ошибка, не задумка)

- LAB08: `probeA over>0`, `qover>0`, `ring_over>0`, `fe>0`, `under` растёт постоянно, звук рвётся,
  ввод с клавиатуры не принимается, enc/dec avg заметно ≠ эталона (~12613/~8940).
- LAB07: не стартует, нет звука, `help` не показывает лесенку, `codec/rate/decim/load/budget` не
  работают, `probeA over>0`.
- Любая: LAB04 и прочие (LAB00/02/03/05) изменили поведение (не должны — их код не тронут).

## Примечание (косметика, не дефект)

Обе таблицы команд компилируются в общий `voice.c` (чтобы все обработчики были ссылаемы, без
unused-warning), поэтому в бинаре КАЖДОЙ работы остаются **help-строки чужой таблицы** как «мёртвые»
rodata (~0.5 КБ, видны в `strings`). На консоль это НЕ влияет: `Console_Register` получает только
свой набор, `help` печатает только свои команды, чужие команды не распознаются. Если понадобится
убрать мёртвые строки — отдельная чистка (гардировать таблицы по LAB_ID с экспортом обработчиков).
